
Controls 🎮
Move around the map with WASD
'F' to toggle flashlight
'Shift' to run
'esc' to open exit menu

🕹️ How to Download and Run CampStillwater (Mac)
Download the ZIP file
Click the link and download CampStillwater.zip to your Mac.

Unzip the file
Double-click the ZIP file to extract it. You’ll get a folder containing CampStillwater.app.

Open the game

Right-click (or Control-click) on CampStillwater.app

Select Open

If you see a warning about it being from an unidentified developer, click Open again in the dialog.
(You only have to do this once.)

🛠️ If the game doesn’t launch:
You may need to give it permission manually:

Open Terminal + type this (adjust the path if needed):

chmod +x ~/Downloads/CampStillwater.app/Contents/MacOS/*
Then try opening it again.
